# PO03-WA-021 — Open opportunity scanner

This unit tests `H-PO03-WA-021`: repository evidence can identify useful
unnamed work by scoring recurring defects, missing recurrence tests, and
high-leverage gaps.

The scanner reads evidence only from the immutable controller source base
`22af3833bd25e2fa1b4e91111c045907e9534119`. Candidate definitions, the
55-point eligibility threshold, weights, population breakpoints, and rejection
controls are frozen in `scanner/scoring-fixture.json`. Evidence generated by
this unit is rejected as circular. Candidates without required evidence and
candidates already named by repository proposals are also rejected.

Run from the repository root:

```sh
python3 -B workstreams/po03/wave-a/units/wa-021/scanner/opportunity_scanner.py \
  --repo . \
  --fixture workstreams/po03/wave-a/units/wa-021/scanner/scoring-fixture.json \
  --output workstreams/po03/wave-a/units/wa-021/result/ranked-opportunities.json \
  --check-determinism

python3 -B -I -m unittest discover \
  -s workstreams/po03/wave-a/units/wa-021/tests \
  -p 'test_*.py' -v
```

The canonical run found two eligible opportunities:

1. Execute the 28 committed Wave A unit recurrence modules in PO-03 CI
   (100/100).
2. Contractually separate requested from provider-attested model and reasoning
   configuration (90/100; eight independent limitation registers).

The 64-instance provenance defect scored 65 but was rejected because
WA-024 already names and verifies that work. Circular and unsupported controls
both scored zero and were rejected.

State separation is explicit:

- `sources/source-claims.json`: source claims only.
- `hypotheses/hypotheses.json`: frozen predictions and refutations only.
- `reproductions/reproduction.json` and `result/ranked-opportunities.json`:
  measured outcomes.
- `proposals/mechanism-changes.json`: unapplied mechanism proposals.
- `proposals/strategy-proposals.json`: coordinator-owned recommendations.

No proposed target was modified. Every target is outside this unit's owned
subtree and remains read-only.
