# HARBOR-17 — external capability brief

Disclosure class: `EXTERNAL_STRICT_CODED`.

This file is the complete external task capsule. It intentionally omits the
principal's identity, affiliation, organisation, repository, internal programme
names, intent beyond the task, and downstream decision use.

## Objective

Discover, reproduce, test, extract and package a provider-neutral capability
factory that can operate at office scale—about one hundred differentiated workers
when useful capacity permits—while counting only durable, independently reviewed
effects.

## Work

- Run disjoint cohorts for frontier research; runtime/model/prompt/skill/context
  qualification; semantic and knowledge governance; adversarial recovery;
  capability extraction; and successor generation.
- Attempt at least 64 non-duplicate units, queue above the measured route ceiling,
  and report capacity only as a tuple of runtime, dispatch and isolation mechanism.
- For every useful mechanism run: discovery or creation, neutral-fixture
  reproduction, independent test, extraction, portable packaging, second-context
  redeployment, and improvement or rejection.
- Treat provider activity and completion as observations. Count a result only
  after manifest, hashes, separate read-back and non-producing review.

## First return

Export `H17-return-v001` with a manifest and SHA-256 hashes, containing a capability
census, denominator ledger, 12 hypotheses, six executable reproductions, two
tested mechanisms or evidence-backed rejections, a recovery exercise, a portable
successor packet, and an explicit open denominator.

## Boundaries

Do not infer or request identity. Do not conduct outreach, purchase, publish,
deploy to production, access private source systems, or self-accept. When private
material is necessary, return the minimum neutral interface or fixture request and
continue unaffected work.
