# Disclosure and codename control — 2026-08-22

Authority: direct founder instruction. Strategy is unchanged. `decision_changed: []`.

Access authority and semantic disclosure are independent. The privileged internal
command layer retains the full strategic frame. Every downstream route must receive
only the context needed for useful performance, classified before launch by task,
trust boundary, persistence and demonstrated need.

| Route | Class | Permitted | Prohibited/default control |
|---|---|---|---|
| ChatGPT Work command layer | `PRIVILEGED_INTERNAL` | Full programme frame and authorised connectors | Do not relay full frame downstream; no secrets in durable non-secret artifacts |
| Cursor on the private repository | `INTERNAL_AUTHORISED_RUNTIME` | Identity, affiliation, repository and strategic execution context needed for repository work | Exact branch/allowlist; secrets and unrelated personal data prohibited |
| SW | `EXTERNAL_STRICT_CODED` | Coded abstract objective, neutral fixtures, minimum technical constraints | Identity, affiliation, repository/org, internal IDs, intent beyond task, downstream decision use, identity-bearing memory/connectors |
| Manus | `EXTERNAL_BOUNDED` | Codenamed operational task and only integrations necessary for that task | Coded task title mandatory; strict prompts reject identity/internal tokens; broader disclosure requires an explicit necessary-disclosure classification and justification |
| Research/browser/public sources | `EXTERNAL_PUBLIC_QUERY` | Abstract query and public facts | No private identifiers or strategic decision frame unless the public referent is strictly necessary |
| Claude/other internal project lane | `INTERNAL_PROJECT_SCOPED` | Only that project's admitted source capsule | No implicit access to other project memory or full command layer |

Default referents are controlled codenames. The internal mapping is stored only in
the privileged layer. External returns keep codenames until the internal layer
screens, hashes and ingests them.

Fail-closed mechanisms now present:

1. The strict SW launch and brief are scanned by the repository validator for
   identity/internal-frame tokens; the old identity-bearing wording fails the test.
2. Manus Edge Function version 8 requires an external codename and disclosure
   classification, rejects strict prompts containing forbidden identity/internal
   tokens, and produces a codenamed task title.
3. Cursor's launch file must declare `INTERNAL_AUTHORISED_RUNTIME`; omission fails
   validation.

The existing private repository cannot be exposed to strict external routes. Use a
codenamed private mirror or object exchange containing screened capsules and neutral
fixtures. Require a denylist scan, manifest, content hashes and two-way read-back.
This costs one private namespace, roughly 15–30 minutes of setup, one screening pass
per exchange and some context-fidelity loss; it does not reduce authorised access or
autonomy inside the privileged layer.
