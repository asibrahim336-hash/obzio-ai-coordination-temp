## 1. Founder outcome

Determine and prepare the strongest feasible route to an **Obzio-controlled, high-capability operator and command system** centred on Ahmed's actual working environment.

The system must use current frontier providers where they add demonstrated value while progressively owning or controlling critical command logic, state, evidence, evaluation, continuity, authority and operator experience. Open-source and open-weight capability is strongly preferred for the owned command layer where representative Obzio tests show it is materially effective.

Return:

1. an evidence-backed target-state recommendation;
2. a staged command-layer migration and cutover plan;
3. Lean, Recommended and Higher-Capability procurement options;
4. an approximately seven-day executable operating plan; and
5. the earliest safe point at which Ahmed can stop using ChatGPT as the routine command interface while retaining ChatGPT wherever it continues to produce demonstrated value.

This programme does not assume that one chatbot replaces another, that one surface is primary, or that any named model/provider is the winner.

## 2. Explicit non-assumptions

Do not assume:

- SW is the primary research, co-worker or command surface;
- Cursor is merely temporary scaffolding or the permanent control plane;
- GitHub is the permanent coordination architecture;
- ChatGPT remains or can become the target permanent primary strategic-lead seat;
- Operator D remains the integrator;
- Claude Extension is the preferred relay or observer;
- Fable 5, GPT-5.6 Sol, Kimi, DeepSeek, Qwen, an open-weight OpenAI family or any other model is the universal winner;
- a provider-native agent object transfers unchanged into Obzio-owned infrastructure; or
- provider marketing, community popularity or cross-model agreement proves strategic reliance.

Treat current surfaces and already-paid capacity as estate to inspect and exploit where justified, not as selected architecture.

## 3. Method authority and operating-fitness rule

Use the strongest current research, engineering and experimental method. Select justified models, tools, temporary agents, repositories, environments, lanes and evaluators. No arbitrary lane, worker, task or step cap applies. Do not manufacture volume.

Every lead lane begins with:

`surface/account | actor/model/mode | tools | source access | write/receipt ability | context completeness | connection/interface reliability | working-room risk | stronger route if any | safe work that continues`

Expose material route defects immediately. Stop affected consequential work, switch to a stronger authorised route where possible and keep independent work moving. Do not silently compress scope or let Ahmed discover degraded work after the fact.

### 5.4 Triangulation

`claim | official/primary evidence | practitioner/community evidence | Obzio trial evidence | disagreement | current verdict | validity/recheck`.

Do not use a universal source hierarchy. W1's approximately 5–10% provider-document share is retained as a useful prior weighting candidate for strategic-method research, not a fixed quota. The actual mix follows claim fit.
