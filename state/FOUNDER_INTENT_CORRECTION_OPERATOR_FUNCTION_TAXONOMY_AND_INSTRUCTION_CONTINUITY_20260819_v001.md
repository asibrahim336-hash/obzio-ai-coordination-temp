## Defect corrected

The repository fossilised conversational and implementation shorthand—such as “Operator D”, “Claude extension”, browser/operator variants and surface-bound job titles—into durable-looking operator identities. Active, predecessor and superseded instructions were not routed through one coherent current stack. This could send a successor to the wrong mandate, narrow delegated authority during a rename or mistake a runtime for an institution.

## Bound correction

1. Durable identity attaches to a constituted Obzio institutional function and appointment, not to a provider, model, browser, extension, account, device or alphabetic shorthand.
2. Conversational labels are evidence of intended meaning, not automatically optimal durable nomenclature.
3. Current instructions must explicitly integrate useful authority, constraints, strategy, continuity and evaluation controls from predecessor records while deliberately superseding, quarantining or retaining the source objects.
4. GitHub operationalises current bound state; publication does not manufacture founder authority.
5. Existing delegated authority remains standing through the migration and is not to be re-requested.
6. The active programme and already-launched v010 execution continue. This correction creates no review, relaunch or founder approval gate.
