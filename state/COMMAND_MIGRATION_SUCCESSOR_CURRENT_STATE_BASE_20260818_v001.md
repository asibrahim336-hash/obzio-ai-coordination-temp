5. **Failure/recovery gate:** interruption, stale context, missing source, tool failure and partial execution enter a safe recoverable state.
6. **Evidence/claim-fit gate:** conclusions carry admissible evidence for the exact proposition; documentation, model agreement and acknowledgement cannot substitute for execution.
7. **Security/rights gate:** secrets, identity, permissions, data rights, least privilege, external effects and production boundaries are enforced.
8. **Portability/substitution gate:** the package can be exported, rebuilt and rehearsed with a material model/runtime substitution; non-portable dependencies are explicit.
9. **Destination-semantic gate:** every destination receives a need-to-know state base that is current at dispatch, not merely hash-consistent.
10. **Independent-acceptance gate:** a separate function using pre-registered criteria reviews raw evidence, dissent, failure and residual risk; the builder does not self-certify.
11. **Rollback gate:** cutover and rollback steps, stop conditions, state reconciliation and legacy fallback are executable and receipted.

No aggregate score, model consensus or founder preference waives a failed hard gate.

Independent Acceptance returns exactly one of:

- `ACCEPT — CUTOVER ELIGIBLE`;
- `ACCEPT WITH NAMED LIMITS — BOUNDED CONTINUATION`;
- `DEFER — DISCRIMINATING EVIDENCE REQUIRED`; or
