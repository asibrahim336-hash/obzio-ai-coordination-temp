# How Browser Automation Works?

HARPA provides a Browser Extension for your Chrome, Brave, Opera, Edge and Chromium browser. This extension comes equipped with web automation engine.

You can think of HARPA Chrome Extension as a worker installed in your browser, completing assigned tasks. Each of such workers is called a Node .

Each Node has a unique ID. You can create and run unlimited number of Nodes with HARPA, one Node per browser profile. For example, you can:

Setup multiple Nodes, one per browser profiles,

Run multiple browser instances on one device,

We cover setup process in our Node Setup Guide .

# Benefits of Browser Automation

Your HARPA Node can do a host of AI-powered time saving workflow automations, specifically, every Node can:

Scrape webpage data, extracting full page content, markdown, or text content by specific CSS, XPath or text selectors,

Launch one of the 100+ built-in AI Commands or your custom web automation scenarios on any webpage,

Search for data, returning links, titles, emails, contact details.

HARPA can also send triggers or execute IFTTT actions in Make.com, Zapier, n8n, Microsoft Power Automate, Workato, UiPath etc. react to updates in web page content, or send data to external services.

# Web Automation Requirements

To run HARPA GRID, you need:

a Chromium based browser and

a stable Internet connection.

If you can browse the Internet, you can use HARPA to automate tasks. Tasks launched by HARPA run in separate browser tab. HARPA uses minimal system resources, and does not consume any while no task is run.

# Supported AI Connections

HARPA Grid uses your default AI connection: OpenAI's GPT-5.4, GPT-5 Nano, Anthropic's Claude Haiku 4.5, Sonnet 4.6, Opus 4.6 and your own API connections.

You can switch between connections in your automations commands mid-run using Connection Flags or AI CONNECTION steps.
